# appsei-skills

Agent skills and plugins for **appse ai** — the AI & Automation Orchestration platform.

Install these in Claude, Cursor, or any MCP-compatible agent to build workflows,
manage integrations, and run platform operations without leaving your editor.

## What's inside
- **Skills** — reusable instruction packs for common appse ai tasks
- **Plugins** — bundled skills, commands, and connectors
- **MCP config** — connect agents directly to the appse ai API
